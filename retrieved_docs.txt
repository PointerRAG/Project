Query: What is mining?
========================================

--- Document 1 ---
Mining Mining is a process by which new blocks are added to the blockchain. Blocks contain transactions that are validated via the mining process by mining nodes on the Bitcoin network. Blocks, once mined and verified are added to the blockchain which keeps the blockchain growing. This process is resource-intensive due to the requirements of PoW where miners compete in order to find a number which is less than the difficulty target of the network

--- Document 2 ---
New coins are minted by the miners by solving the PoW problem, also known as partial hash inversion problem. This process consumes a high amount of resources including computing power and electricity. This process also secures the system against frauds and double spending attacks while adding more virtual currency to the Bitcoin ecosystem. Roughly one new block is created (mined) every 10 minutes. This frequency needs to be maintained by the Bitcoin network. Miners are rewarded with new coins if and when they discover new blocks by solving PoW

Query: properties of smart contracts

--- Document 1 ---
A smart contract has the following four properties: 1. Automatically executable: runs on a blockchain without any intervention 2. Enforceable: all contract conditions are enforced automatically 3. Semantically sound: tamper-proof and run with security guarantees 4. Secure and unstoppable: ensures that smart contracts always produce the same output for a specific input

--- Document 2 ---
Smart Contracts Definition A smart contract is a secure and unstoppable computer program representing an agreement that is automatically executable and enforceable. Secure and unstoppable: Means that these computer programs are required to be designed in such a fashion that they are fault-tolerant and executable in a reasonable amount of time. These programs should be able to execute and maintain a healthy internal state, even if external factors are unfavorable. Smart contracts are self-enforcing as opposed to legally enforceable. Smart contracts are not really smart, they are simply doing what they are programmed to do.
